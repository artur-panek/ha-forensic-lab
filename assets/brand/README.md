# HA Forensic Lab visual identity

The production mark is derived from the selected **waveform + trace lens** concept.

## Meaning

- **Waveform** — runtime activity and the event stream.
- **Magnifying glass** — forensic investigation rather than passive monitoring.
- **Trace nodes** — Home Assistant context and execution paths.
- **Amber node** — the selected evidence point under investigation.

## Palette

| Role | Value |
| --- | --- |
| Cyan highlight | `#25D9F1` |
| Cyan core | `#19C8E4` |
| Cyan deep | `#0789A8` |
| Graphite | `#1E313C` |
| Graphite dark | `#111C24` |
| Evidence amber | `#FFB21B` |

## Usage

- Use `ha-forensic-lab-mark.svg` as the source artwork.
- The HACS integration icon is generated from the same mark.
- Keep the mark free of slogans or extra text at icon sizes.
- Amber is reserved for an evidence/point-of-interest accent, not general decoration.
- Do not add detective hats, badges, eyes, police imagery or other literal detective clichés.

The mark should remain readable on both light and dark Home Assistant themes.
