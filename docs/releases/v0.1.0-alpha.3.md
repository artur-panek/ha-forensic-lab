# 0.1.0-alpha.3 — release candidate

Adds anchored paging through retained timeline events and verified rolling checkpoints with retry after storage failure. The panel keeps older pages available for inspection, explanation and incident capture; an evicted cursor requires refresh.

The advisory target is Home Assistant 2026.11.0. Minimum support remains 2026.9.4. This source candidate has not been published or tested on a real Home Assistant installation. Run the existing alpha acceptance checklist, including browser workflows, restart/restore and the configured persistence interval, before publishing it.

Saved history remains bounded and cannot recover events already evicted or reconstruct unrecorded actions. Stopping-phase deferred Store writes are distinguished from verified checkpoints. Existing source fixes since alpha.2 are included in the candidate; published-install instructions continue to refer to alpha.2 until a release is approved.
