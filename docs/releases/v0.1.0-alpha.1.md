## First experimental alpha

Record Home Assistant state changes and service calls, inspect their available context links, and save the relevant events as an incident for later review.

This release contains the runtime code reviewed at `1fab191831e675c473053e004d8f4165d69a6b7c`, including the fixes for direct script exclusions and invalid stored timestamps. It is published for real-instance testing; the installation, restart and normal-use performance checklist is still open.

### Install through HACS

HA Forensic Lab is a HACS custom repository, not a default-catalogue integration. Requires Home Assistant **2026.9.4 or newer** and an administrator account.

For an existing HACS installation, open **HA Forensic Lab**, enable **Show beta versions** in its menu, and select **v0.1.0-alpha.1** when downloading or updating. Restart Home Assistant. A `main` installation may require **Redownload** to select the tagged version.

For a first installation, add `https://github.com/artur-panek/ha-forensic-lab` as an **Integration** custom repository, download this version, restart Home Assistant, then add **HA Forensic Lab** under **Settings → Devices & services**.

Take a Home Assistant backup before installing. The ZIP and checksum are attached for manual installation; HACS does not require them to be downloaded separately.

### Included

- Bounded event capture with entity/domain exclusions and configurable persistence.
- An administrator-only timeline with context-linked evidence and explicit gaps.
- Saved incidents, retained trace structure, review after restart and sanitized ZIP export.
- Capture and storage diagnostics, including retained history and filtered-event counts.

### Limits to keep in mind

- Context links and captured ordering do not prove a root cause.
- Hard crashes can lose events since the last rolling snapshot. The default interval is 10 seconds.
- The default rolling buffer holds 2,048 events. Saved incidents are limited to 50, with at most 500 events each.
- Raw service payloads, state attributes and trace variables are not retained. Attribute-only state updates are skipped by default.
- Exclusion changes re-filter rolling data, not incidents already saved by the user.
- Review sanitized exports before sharing; domains, relative timing and execution structure remain visible.

Automated checks cover Python and frontend regressions, packaging, HACS/hassfest validation, and Home Assistant helper compatibility. They do not replace the [real-instance checklist](https://github.com/artur-panek/ha-forensic-lab/blob/v0.1.0-alpha.1/docs/alpha-release-checklist.md).

The first useful live test is **capture → save incident → restart Home Assistant → review the saved incident → export**. Report problems with the HA version, integration version and sanitized diagnostics; do not upload raw Home Assistant traces.
