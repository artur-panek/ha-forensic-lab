# v0.1 scope

## Goal

Ship the smallest version of HA Forensic Lab that can answer a useful forensic question:

> An entity changed. What runtime evidence explains that change?

v0.1 is not a general monitoring suite and it is not an AI root-cause engine.

## In scope

### 1. Bounded runtime capture

Capture a normalized subset of Home Assistant runtime evidence, initially centered on:

- state changes
- service calls
- automation-triggered events
- script-started events
- Home Assistant context IDs and parent context IDs
- timestamps and the smallest useful payload for reconstruction

Raw payload retention must be bounded.

### 2. Timeline

Provide a searchable timeline that can be filtered by:

- time range
- entity
- automation
- script
- service/domain
- context ID

### 3. Causality reconstruction

Build directed relationships between events.

Every edge must be classified as one of:

- confirmed
- correlated

The classification must be stored with the edge, not inferred only by the frontend.

### 4. Explain this change

Given a selected entity state change, return:

- the state transition
- the best known upstream trigger or actor
- intermediate automation/script/service steps
- confidence/evidence class for every relationship
- explicit gaps where Home Assistant did not expose enough evidence

### 5. Saved incidents

Allow an administrator to freeze a time window into a durable incident.

An incident should include normalized evidence plus references to any captured trace material needed for reconstruction.

### 6. Sanitized export

Export a saved incident in a portable bundle suitable for attaching to an issue.

Default export must remove or redact sensitive values where practical.

## Explicit non-goals for v0.1

- host CPU/RAM/kernel monitoring
- crash dump collection
- anomaly detection
- LLM-generated root-cause analysis
- long-term replacement for Home Assistant Recorder
- automatic modification of automations
- remote/cloud telemetry
- non-admin access

## Acceptance criteria

v0.1 is useful when all of the following are true:

1. A user can select a recorded entity state change.
2. HA Forensic Lab can show the surrounding event sequence.
3. Context-backed causal links are distinguishable from time correlations.
4. Missing evidence is shown as unknown rather than guessed.
5. A useful incident can be saved and exported.
6. Retention is bounded and documented.
7. Disabling/uninstalling the integration stops capture without affecting normal Home Assistant operation.
